# 원본 JS·CSS 보관

이 폴더는 `cnstkal/ai` 저장소에서 가져온 앱별 JavaScript와 CSS 원본 파일을 독립적으로 보관합니다.

- `js/`: 앱 동작 코드
- `css/`: 앱 화면 스타일
- HTML 파일은 가져오지 않습니다.
- 기존 `chapters/*/apps` 파일과 연결하거나 덮어쓰지 않습니다.
- 기존 앱의 코드·화면·데이터를 수정하지 않습니다.
- 이 폴더의 파일은 원본 보관용이며, 별도 연결 작업 전까지 실행 화면에 적용되지 않습니다.
- 챕터 화면의 표시 언어는 한국어로 고정합니다.

원본: https://github.com/cnstkal/ai
