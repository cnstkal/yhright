# Messages

2020년 iPhone 12 / iOS 14 기본 메시지 앱 폴더.

- `messages.html`, `messages.css`, `messages.js`
- 대화 목록: 편집·새 메시지·검색, 고정 대화(최대 9개, 읽지 않음 표시·입력 중 표시), 최근 메시지 순 목록
- 대화 화면: 뒤로 가기(읽지 않은 수 표시), 프로필·이름, 말풍선(iMessage 파랑 / SMS 초록 / 상대 회색), 시간 구분선, 읽음·전송됨 표시, 사진 첨부 자리, 그룹 발신자 이름
- 입력창: 앱 추가 버튼, 음성 메시지 버튼, 입력 시 보내기 버튼으로 전환
- 답장: 말풍선을 더블클릭하면 인라인 답장 대상으로 지정됩니다. `@이름` 멘션은 파란색으로 표시됩니다.
- 전송은 시뮬레이션입니다. 대화 기록은 브라우저 저장소(localStorage)에 남습니다.
