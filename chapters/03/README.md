# 03

## 시점 및 기기
- 시점: 윤호가 스무 살이 된 이후, 고등학교 졸업 후
- 기기: iPhone 11
- OS 기준: iOS 13 UI
- 정확한 연도와 날짜는 별도 지정 전까지 고정하지 않음

## 정윤호의 생활
- 고등학교 졸업 후 여러 곳에서 아르바이트하며 생활비를 벌어 생활함.
- 한동안 모텔에서 지냈지만 꾸준히 돈을 모아 어느 정도 여유가 생긴 뒤 모텔을 나와 독립해 생활 중.
- 현재 모아 둔 돈은 약 700만 원.
- 스무 살 무렵 자신이 게이라는 사실을 자각함.
- 남성 만남 앱을 사용하기 시작했고 연락을 보내는 사람은 많지만, 막상 마음에 드는 사람도 드물고 두려움이 커서 답장을 잘하지 못함.

## 박성화와의 관계
- 앱에서 만난 사람 중 가장 젠틀했던 사용자가 mars.
- mars의 실제 이름은 박성화. 20대 후반의 회사원이며 평범한 중소기업에서 대리로 근무함.
- 성화는 윤호의 생활 형편이 여의치 않다는 사실을 알게 된 뒤 자신의 집에서 윤호가 지낼 수 있게 해줌.
- 두 사람은 성화의 집에서 함께 살며 연애했고, 관계는 대체로 안정적이고 다정했음.
- 두 사람은 큰 싸움이나 원망 없이 각자의 시기가 되어 헤어짐.
- 헤어질 때 얼굴을 붉히지 않았고, 종종 연락하자고 약속함.
- 윤호는 성화의 집을 떠나 다시 독립적인 생활을 시작함.

## 앱 반영 원칙
- Tinder에는 윤호가 여러 사람의 연락을 받지만 쉽게 답하지 못하는 모습과 mars의 차분하고 배려 있는 첫 대화를 반영.
- 카카오톡은 정윤호가 사용하는 기기로 설정하고, 박성화와 함께 살던 시기의 평범하고 안정적인 일상 대화를 반영.
- 신한은행 계좌는 윤호의 저축액이 약 700만 원인 상태를 기준으로 함. 임의의 큰 소비나 부유한 생활을 추가하지 않음.
- 03의 앱과 데이터는 03 내부에서 독립적으로 동작하며 한국어 UI를 유지.
