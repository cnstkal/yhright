# 03. 연예인

이 폴더는 3장 전용 스마트폰 환경입니다.

## 독립 구조
- `home.html`: 3장 전용 홈 화면 (기기·연도·디자인 확정 후 제작)
- `system-bar.js`: 3장 전용 상태바
- `css/`: 홈 화면 및 기기 스타일
- `assets/`: 배경화면과 홈 화면 이미지
- `apps/`: 이 챕터에서 실제 사용하는 앱만 배치

## 작업 원칙
- 1장·2장의 화면, 데이터, 앱 파일을 수정하거나 공유하지 않습니다.
- 앱별 HTML·CSS·JS·이미지는 각 앱 폴더 안에 독립 보관합니다.
- 언어는 한국어로 고정합니다.
- 원문에서 확인되지 않은 사건·대화·앱 데이터는 임의로 만들지 않습니다.
- 앱 목록은 원문 확인 전까지 제안 단계이며, 확정된 앱만 실제 홈 화면에 표시합니다.

## 앱 구성 제안
- 카카오톡: 인물 간 사적인 연락과 단체 대화가 원문에 있을 때 사용
- 전화: 통화·부재중 기록이 장면에 등장할 때 사용
- 사진/카메라: 촬영·사진 공유·앨범 확인 장면이 있을 때 사용
- 인스타그램: 공개 프로필, 게시물, 댓글, DM 등 SNS 활동이 원문에 있을 때 사용
- 캘린더: 촬영·방송·행사 등 일정 관리가 실제로 필요할 때 사용
- 검색/뉴스: 연예 관련 기사나 인물 검색을 윤호가 직접 확인하는 장면이 있을 때 사용

위 항목은 연예인이라는 챕터명에서 도출한 후보이며, 원문으로 확정한 사실은 아닙니다.
