# Phone

2020년 iPhone 12 / iOS 14 기본 전화 앱 폴더.

- `phone.html` — 전화 화면
- `phone.css` — 스타일 (iOS 14 흰색 기본 디자인, 하단 5개 탭, 연락처 상세, 수신 배너)
- `phone.js` — 탭 전환, 최근 통화 전체/부재중, 연락처 검색·상세, 키패드 입력·삭제, 음성 사서함 목록, 수신 배너(기본) / 잠금 화면 수신 UI(`?lock`)

통화 발신·수락·거절 버튼은 외형만 있고 실제 통화는 연결되지 않습니다. 사진은 이니셜 원형 아바타로 대체했습니다.
