# 02. 집

## 구조

- `home.html`: 이 챕터 전용 홈 화면
- `system-bar.js`: 카카오톡 등 앱에서 사용하는 시스템바
- `apps/Blind.html`: 블라인드 시뮬레이션
- `apps/Kakaotalk.html`: 카카오톡 진입 HTML
- `apps/Kakaotalk/css/`: 카카오톡 스타일
- `apps/Kakaotalk/js/`: 카카오톡 동작 코드

각 챕터의 홈 화면, 시스템 UI, 앱 데이터는 독립적으로 관리합니다.
화면 언어는 한국어로 고정하며 다국어(i18n) 기능은 사용하지 않습니다.
