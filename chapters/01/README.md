# 01

- 기준 시점: 2017년 9월
- 기본 가상 날짜: 2017년 9월 4일
- 기기: Samsung Galaxy S7 / Android 6.0 / TouchWiz
- 휴대폰 주인: 정윤호
- 신분: 서린고등학교 1학년 (가상의 학교)
- 주요 인물: 이모, 종호, 이모부

## 인물 및 데이터 기준
- 페이스북 계정 이름은 정윤호이며, 프로필에 서린고등학교 1학년으로 표시합니다.
- 전화번호부에는 엄마, 아빠, 형, 이모, 이모부, 종호와 학교 친구들이 있습니다.
- 즐겨찾기는 엄마와 아빠만 등록합니다.
- 형과의 최근 통화 기록은 없습니다.
- 엄마·아빠와는 오랫동안 연락하지 않은 상태이며, 이모·종호·이모부와 상대적으로 자주 연락합니다.
- 메모는 준비물, 숙제, 학교생활에 관한 짧고 평범한 내용으로 구성합니다.
- 새로 생성되는 게시물, 메모, 통화, 메시지, 사진의 날짜도 2017년 기준으로 기록합니다.

## 구조
- `home.html`: 기기 프레임, 홈 화면, 상태바, 앱 실행용 디스플레이
- `chapter-clock.js`: 챕터 1 전용 2017년 가상 시계
- `css/device.css`: 기기 외형
- `assets/`: 배경화면
- 앱별 폴더: 해당 앱의 HTML·CSS·JS·이미지

## 구현 메모
- 챕터 1의 앱은 공통 가상 시계를 사용합니다.
- 홈 화면과 하단 독은 이 챕터 전용으로 유지합니다.
- 앱 전용 파일은 해당 앱 폴더 안에 둡니다.
- 사진 앱과 카메라 앱은 2017년 전용 저장 키를 사용합니다.
