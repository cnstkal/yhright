# 01. 동생

- 시점: 2016년
- 기기: Samsung Galaxy S7 / Android 6.0 / TouchWiz
- 윤호: 1999년생, 고등학생
- 주요 인물: 최종호

## 구조

- `home.html`: 기기 프레임, 홈 화면, 상태바, 앱 실행용 디스플레이
- `css/device.css`: Galaxy S7 기기 외형
- `css/touchwiz-home.css`: TouchWiz 홈 화면
- `assets/wallpaper.svg`: 배경화면
- `system-bar.js`: 이 챕터 앱에서 재사용할 시스템바 스크립트
- `메모앱/`: 메모 앱 HTML·CSS·JS

## 구현 메모

- 홈 화면과 하단 독은 이 챕터 전용으로 유지합니다.
- 메모 앱은 `메모앱/notes.html`에서 실행합니다.
- 홈 화면의 메모 아이콘은 해당 파일을 직접 엽니다.
- 삭제된 전화·메시지·사진 앱은 다시 연결하지 않습니다.
