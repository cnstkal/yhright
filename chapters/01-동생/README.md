# 01. 동생

- 시점: 2016년
- 윤호: 1999년생, 고등학생
- 주요 인물: 최종호

## 앱
- 메시지
- 전화
- 사진
- 메모

각 앱은 이 챕터의 독립된 휴대폰 데이터로 구성합니다.

## 독립 UI
- 홈 화면과 하단 독은 `home.html`에 별도로 구성합니다.
- 시스템바와 번역 스크립트는 챕터 내부 파일을 사용합니다.

## 진행 기록 (Galaxy S7 / TouchWiz)
- 기준: Galaxy S7 SM-G930, Android 6.0. 1mm ≈ 5.68px, 화면 360×640, 기기 395×809.
- 구조: `home.html`(마크업) · `css/device.css`(기기 외형) · `css/touchwiz-home.css`(홈 화면) · `assets/wallpaper.svg`.
- 완료: 기기 목업(프레임, 수화부, 카메라, 센서, 물리 홈버튼, 최근·뒤로 키), 상태바, 시계·날씨 위젯, 앱 아이콘, 독, 페이지 인디케이터.
- 남음: 앱 서랍, 앱 화면을 `.screen` 안에 넣기(현재 앱 HTML은 구 iOS풍 단독 페이지), 아이콘·배경화면 실물 대조 보정, 알림창.
- 2차 수정: 메모 앱을 2016 삼성 메모 스타일(평면, 직각 모서리, 주황 강조, 안드로이드 상태바)로 덮어쓰기(`apps/notes.html` 하단 CSS 블록), 목업 확대(여백 축소).
- 남음: 첨부 이미지 대조 보정(이미지 미수신), 홈 화면 아이콘·위젯·배경 재검토, 메모 앱 하단 툴바/편집 화면 세부 보정.
- 3차 수정: 공통 PhoneFrame 구조. `home.html`이 기기 프레임을 한 번만 그리고 `.screen` 안의 iframe(`#disp`)에서 홈 화면과 모든 앱이 열림. 앱 안에서 `../home.html`로 이동하면 iframe 내부에서는 홈 화면만 표시(`html.emb`). 물리 홈버튼=홈 화면, 뒤로 키=iframe 뒤로가기.
- 홈 화면: 첨부 S7 이미지 기준(남색+파란 곡선 배경, 크림색 폴더·계산기·캘린더·카메라·시계·갤러리·메모 등 아이콘, 40%·오후 12:08 형식 상태바).
- 메모 앱: 목록(제목+미리보기+카테고리, 검색·더보기), 작성(제목/본문, 카테고리·작업·이미지·그리기·음성·저장).
- 남음: 전화·메시지·갤러리 앱은 구 디자인 그대로(수정 금지 상태), 앱 서랍, 최근 앱 키 동작, 음성 녹음은 브라우저 마이크 허용 필요.
