# YH RIGHT

소설 기반 스마트폰 시뮬레이션 게임.

## 저장소 구조

- `index.html`: 게임 진입점. 첫 번째 챕터로 이동합니다.
- `chapters/`: 챕터별 스마트폰 환경과 앱을 보관합니다.
- `imports/ai/`: `cnstkal/ai`에서 가져온 앱별 CSS·JS 원본 보관소입니다. 직접 실행되는 파일이 아닙니다.

## 챕터 구성 원칙

- 각 챕터는 `home.html`과 자체 시스템 UI를 독립적으로 관리합니다.
- 앱은 해당 챕터 폴더 안에 두고, 앱 전용 CSS·JS는 앱 폴더 안에 둡니다.
- 챕터 간 화면·데이터·진행 상태를 공유하지 않습니다.
- 다국어(i18n) 기능은 사용하지 않으며 화면 언어는 한국어로 고정합니다.

원본 앱 보관소: https://github.com/cnstkal/ai
