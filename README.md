# YH RIGHT

소설 기반 스마트폰 시뮬레이션 게임.

## 구조 원칙
- `chapters/`: 챕터별로 독립된 스마트폰 환경과 앱을 관리합니다.
- 각 챕터 폴더에 `home.html`, `system-bar.js`, `i18n.js` 등 해당 시기의 UI 파일을 둡니다.
- 홈 화면, 상태바, 하단 독/내비게이션은 챕터 간 공유하지 않습니다.
- 앱 전용 CSS·JS·이미지 등은 해당 앱 폴더 안에 둡니다.
- 여러 챕터에서 같은 앱을 사용해도 화면 디자인, 데이터, 진행 상태를 챕터별로 분리합니다.
- 기존 `shared/` 폴더는 이전 구조의 잔여 파일이며, 신규 작업에서는 사용하지 않습니다.

원본 앱 보관소: https://github.com/cnstkal/ai
